5. Other Functionality

The SPCD3 parallel coordinates component used in the chart also provides some additional functionality in its toolbar, which can be accessed pressing the aa button:

  • Show Table

    Displays the dataset in tabular form and allows it to be downloaded as a CSV file.

    Click the Show Table button and download the dataset as a CSV file.

  • Download Chart (SVG)

    Allows the chart to be downloaded in Scalable Vector Graphics (SVG) format.

    Click the Download Chart (SVG) button and save the chart as SVG.

  • Refresh

    Draws the chart again, in case of any rendering issues.

    Click the Refresh button to redraw the chart (will generally not change the display).

  • Reset

    Resets the chart to its original state.

    Set a filter, then click the Reset button to return the chart to its original state.
